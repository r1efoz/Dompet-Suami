# Rencana Kerja — Revamp UI Dompet Suami

Spesifikasi: `docs/design.md` (layar) dan `docs/design-system.md` (token/komponen, disingkat DS). Status serah terima: `docs/handoff/revamp-ui.md`. Aturan lingkungan: `AGENTS.md`.

## Cara memakai rencana ini

1. Kerjakan **satu tugas** per sesi chat. Jangan loncat. Jangan menggabungkan dua tugas.
2. Tiap tugas punya: **Boleh sentuh** (hanya file ini), **Jangan sentuh**, **Tes dulu** (tulis & jalankan sebelum kode produksi; harus merah dulu), **Langkah**, **Verifikasi** (perintah + hasil yang diharapkan), **Selesai bila** (centang semua).
3. Setelah tugas selesai dan verifikasi hijau: `git add` hanya file tugas itu, commit dengan pesan yang tertulis, lalu tulis 3–5 baris di `docs/handoff/revamp-ui.md` bagian "Log", lalu **berhenti** dan laporkan.
4. Kalau ada yang tidak jelas: tulis pertanyaannya di handoff bagian "Pertanyaan", pilih tafsir paling sederhana yang **tidak** melanggar DS, lanjutkan, dan sebut tafsir itu di laporan.
5. Dilarang: menambah dependency, mengubah skema DB selain yang disebut, membaca `.env`, menjalankan perintah ke Supabase hosted, memakai runes Svelte.

Perintah dasar:

```bash
npm run dev          # http://localhost:5173 (kalau 5173 dipakai, Vite pindah ke 5174/5175 — cek output)
npm run check        # self-check logika (tsx)
npm run test:ui      # e2e Playwright, butuh dev server di :5173
npm run build        # harus lolos tanpa warning Svelte
```

Baseline sebelum Tugas 1 (jalankan dan catat hasilnya di handoff): `npm run check` → baris terakhir `… 10 assertions passed`; `npm run build` → sukses. **`npm run test:ui` saat ini diketahui merah** (menulis ke DB nyata, mengharapkan saldo bank 4.000.000 yang tidak mungkin dengan data yang ada, dan memakai seed `localStorage` yang sudah mati). Jangan memperbaikinya di baseline; Tugas 1 membuatnya deterministik. Catat saja hasil merahnya.

Catatan DB lokal: DB mungkin berisi data uji coba manual (misal akun "CONTOH DUMMY"). Sebelum pemeriksaan visual, muat `supabase/seed.local.sql` (lihat `design.md` §7). Sebelum e2e, tidak perlu apa-apa — e2e memuat `seed.e2e.sql` sendiri.
